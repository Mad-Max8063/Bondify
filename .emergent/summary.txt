**what currently exists?**
Se ha desarrollado una aplicación full-stack completamente funcional.
-   **Frontend:** Una aplicación React + TypeScript con Vite y TailwindCSS. La interfaz principal es un mapa interactivo (Leaflet) que muestra la ubicación de los colectivos en tiempo real. Incluye un completo sistema de reportes comunitarios tipo Waze, perfiles de usuario con favoritos e historial, y un flujo para que los usuarios compartan su ubicación GPS para actuar como colectivos reales.
-   **Backend:** Un servidor Node.js/Express conectado a una base de datos MongoDB. Proporciona APIs para gestionar la ubicación de los colectivos, los perfiles de usuario, los reportes comunitarios (con votación y confirmación), y la integración con IA (Google Gemini) para analizar incidentes.
-   **Simulador:** Un script () se ejecuta en segundo plano para generar datos de colectivos simulados, alimentando el backend.
-   **Problema Conocido:** Los tiles (baldosas) del mapa de Leaflet no se cargan correctamente en el entorno de previsualización, mostrando un fondo gris. Se ha implementado una solución visual para que la app siga siendo usable y se ha determinado que es una limitación del entorno.
